These standardized classifiers can then be used by community members to find projects based on their desired criteria. Instructions for how to add Trove classifiers to a project can be found on the Python Packaging User Guide . To read the original classifier specification, refer to PEP 301 . To prevent a package from being uploaded to PyPI, use the special "Private :: Do Not Upload" classifier. PyPI will always reject packages with classifiers beginning with "Private ::".
