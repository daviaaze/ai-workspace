Wiki is an open-source wiki management application built on the Frappe Framework. It's designed to handle dynamic, text-heavy content like documentation and knowledge bases. Think of it as a flexible content management system that allows for quick publishing of small changes and new pages without requiring deployments Why Wiki? Because managing knowledge shouldn't be complicated. Your wiki should be easy to use, flexible, and powerful. With Wiki, you get: An open-source solution that you can customize to your needs Built on the robust Frappe Framework, ensuring scalability and reliability No vendor lock-in - you own your data and have freedom to modify Key Features Wiki will help you to: Create and manage wiki pages Organize content with wiki spaces Set up controlled wiki updates with approval mechanisms Add attachments to pages Generate automatic table of contents Maintain version history of documents Use markdown format for content authoring Caching for fast load times Support custom scripts via wiki settings Edit dynamic sidebar through drag-and-drop Under the Hood Frappe Framework : A full-stack web application framework written in Python and JavaScript. The framework provides a robust foundation for building web applications, including a database abstraction layer, user authentication, and a REST API.
