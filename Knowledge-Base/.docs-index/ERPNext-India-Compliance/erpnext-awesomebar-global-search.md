It helps users jump to pages, open reports, create new documents, and search for records without navigating through modules or menus. Opening the Awesomebar Use the Search option in the Desk sidebar, or press Ctrl + K on Windows/Linux and Cmd + K on macOS. The Awesomebar opens as a centered search panel over the current page. Search Records Directly When you type a value in the Awesomebar, ERPNext can suggest direct record searches such as Find spindl in Cost Center . This lets users search records from the current context without opening the DocType list first. Find Similar Names Across DocTypes The Awesomebar also matches similar names across DocTypes, reports, tree views, setup pages, and other Desk actions. For example, typing customer returns results such as Customer, Customer Group, Customer Feedback, Customs Tariff Number, customer reports, and the option to search for the typed value. Benefits Faster navigation: Users can open pages and reports without remembering where they are located in the module tree. Direct record lookup: Users can search for matching records from the Awesomebar itself. Cross-DocType discovery: Similar names are matched across DocTypes, reports, commands, and other Desk actions. Less context switching: The Awesomebar works from most Desk pages, so users can move to another task without returning to the workspace first. Keyboard-friendly workflow: Users can open the Awesomebar, navigate results, and select an option using the keyboard. Example If a user types customer , the Awesomebar can show Customer List, Customer Report, New Customer, Customer Group, Customer Feedback, customer-related reports, and record search options. This makes it useful for both experienced users who know what they want and new users who are exploring ERPNext terminology.
