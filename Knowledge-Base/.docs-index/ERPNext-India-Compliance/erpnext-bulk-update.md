To access Bulk Update, go to: Home > Bulk Update Consider that you have 20 quotations in which you had selected 'All Territories' and now you want to change the Territory to France. Instead of updating the individual quotations manually, you can use Bulk Update to update all 20 Quotations at once. To do this, Go to Bulk Update. Select the Document Type, like Quotation. Select the field to update, like territory. Enter a valid new value to be updated. Enter any conditions that apply, for example: {"status":"Draft"} will only affect documents in the Draft stage.
