These views bring important information into one place so users can review trends, exceptions, transactions, and operational status without opening each document individually. Dashboards are useful for day-to-day monitoring, while reports and analytics pages are useful for deeper review. In practice, most ERPNext teams use a combination of module workspaces, dashboards, and reports. Choosing The Right Dashboard Use a module dashboard or report when you want to monitor a specific area of ERPNext: Use Accounting Reports for financial review. Use Sales Reports for sales performance. Use Buying Reports for procurement tracking. Use Stock Level Report and Stock Ledger Report for inventory monitoring. Use Manufacturing Dashboard and Production Analytics for production review. Use Project Reports for project tracking. Use Support Reports for customer support review. Use Insights Dashboards when you need custom dashboards across modules.
