Error message indicates problem is in the existing permission setting for this document. For any role, before assigning permission at Perm Level 1 or 2 (and so on), permission at Perm Level 0 must be assigned. Error message says that System Manager has been assigned permission at Perm Level 1 and 2, but not at level 0. You should first correct the permission for System Manager's role by: Assigning permission to System Manager at level 0. Or By removing permission at level 1 and 2.
