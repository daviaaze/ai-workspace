Expected version ">=18.0.0". Got "16.16.0" error Found incompatible module. It means that Node version on your bench group is different from what is required by the app. To fix this issue: Navigate to the Dependencies tab on your Bench Group Locate the Node Version entry Click on Edit under the ··· menu button: ℹ️ Tip To set a custom dependency version view this documentation page . You should see an Edit Dependency dialog pop up: Select the correct Node Version, click on Edit to save the setting. Then try updating your Bench Group.
