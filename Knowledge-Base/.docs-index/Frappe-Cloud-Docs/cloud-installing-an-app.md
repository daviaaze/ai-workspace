To install an app Click on Apps tab of your Site's dashboard Click on Install App Select the app you need to install Sites on Private bench groups You can add custom apps or any app from the marketplace to your bench group and then install to your site. To install an app on a site on private bench group you have to add app in 2 places. Bench Group Click on Apps tab of your Bench Group's dashboard Click on Add App Select any marketplace app or follow this guide to install a custom app. Click on the Update Available button to create a new deploy so that your site can install the app Select your site while doing the update and click on deploy and update Site Once the update is done click on Apps tab of your Site's dashboard Click on Install App Select the app added earlier to install Last updated 6 months ago Was this helpful?
