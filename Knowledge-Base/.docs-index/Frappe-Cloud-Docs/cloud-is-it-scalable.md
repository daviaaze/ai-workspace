Vertical Scaling : Frappe Cloud has a diverse set of plans to choose from across cloud providers. They provide a range of specifications be it for sites or servers. (Find more information on plans here .) Horizontal Scaling : Frappe Cloud is equipped with autoscaling. This feature allows you to set up a parallel application server (in addition to your primary server) on demand. You can do it manually, or schedule it based on your load spike expectations. You can also set thresholds on compute to scale automatically. Additionally, for enterprises with extremely variable and/or growing workloads, Frappe also provides consulting for architecture and performance.
