Autoscaling Autoscaling is a form of horizontal scaling that enables automatic scaling when your servers are accosted by expected or unexpected load spikes. It creates a secondary server in parallel to your primary server and distributes the load between the two intelligently so as to minimise impact on user experience. Frappe Cloud is equipped with autoscaling. You can create the secondary server manually or schedule it for a specific time period when you expect a load spike. Alternatively, you can also set up thresholds of compute/usage to automatically trigger the secondary server when load spikes and roll it back when the load subsides.
