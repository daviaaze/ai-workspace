Shared hosting has multiple sites sharing server resources making it very cost-effective. Representation of sites and bench groups in a common server Site: Your private database instance When you create a new instance of a Frappe application you create a site that looks like nova.erpnext.com . A site is a dedicated database housed in a common server. Like any other web-based SaaS application, multiple sites share the resources of a single server. You can customise the subdomain for your site or continue with the default subdomain. You can install multiple Frappe applications on one site. Yes, you heard that right! You don't have to pay separately for any new apps. Private and Shared Bench Groups Bench groups are a stack of containers to host multiple sites in an isolated environment for specific versions and applications. Bench groups offer you increased customisation capabilities. Any new site is by default created under a shared bench group which is managed by Frappe's team. Shared bench groups simplify hosting tasks such as automated upgrades and quick access to 15+ Frappe applications. It's ideal for companies looking for out-of-the-box apps with minimal customisations. Hosting your sites on private bench groups creates an isolated environment for deployments and unlocks deeper controls for them. It helps you manage your upgrades, install custom apps, get SSH access, and more. With a private bench group, you get access to 150+ ready-to-use Frappe applications available on Marketplace . Have a look at the comparison between shared vs private bench groups. Yes! You're not dreaming. There is no restriction on the number of apps that you can install in one site. You can install as many applications in a single site and start using it. Unlike other proprietary software, we don't charge per app, per module or per user. Is there a per-user limit? Sites created with any of the plans do not have any user limit. However, these sites are limited by CPU hours per day. This means if there are a lot of users using the site, the site may slow down if the CPU usage limit is reached. For a detailed explanation read a blog that explains this. Click here to read Where are the servers hosted and where is the data stored? We host most of our servers with Amazon Web Services (AWS EC2), while a few are hosted via OCI (KSA). You can choose your data center location across 5 continents and 10 countries. Can I switch (downgrade or upgrade) my plan later? Yes, if you are unsure which shared hosting plan is best suited for you, just start with any plan (e.g., $10/month) and monitor your usage on the Frappe Cloud Dashboard. How do I make payments? You can choose from 2 payment modes: Pay via card: The Invoice amount will be deducted directly from your card at the end of the month. Pay via prepaid credit: First, you add money to your prepaid credit wallet using your card, PayPal, or additional payment modes based on your region. The invoice will be deducted from your credit balance at the end of each month. While paying via prepaid credit you should ensure that the necessary credits are available in your wallet for uninterrupted services. How do I set up my payments? Go to your Account settings by clicking on your name on the bottom left corner, and go to the Billing tab. Click on the Set up Payment Method button and add your card details. After this is successful, a monthly subscription for you will be created.
