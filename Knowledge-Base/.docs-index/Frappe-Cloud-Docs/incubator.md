FRAPPE INCUBATOR Build amazing software with Frappe Frappe Incubator aims to provide monetary and marketing support to Frappe community contributors and facilitate the development of outstanding Frappe apps using Frappe Framework. Incubatees get a funding of up to ₹10 lakh / USD $10,000 while building a product for the Frappe ecosystem: Frappe Framework, Frappe Cloud, or Frappe UI. Frappe Incubator is a program that funds open source tools built on Frappe Framework. Let’s take off! Benefits Pitch. Build. Launch. Monetary Support Kickstart your project with up to INR 10L or USD 10K investment from Frappe. Access the funds as per your planned milestones. Design Help While you build the project the way you want to, we have your back with everything design, from product UIs to the website. Marketing Aid Social media shout-outs, Frappe newsletter mentions, and Frappe Cloud Marketplace listing for your project.
