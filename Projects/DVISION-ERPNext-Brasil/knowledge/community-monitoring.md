## 7. O que Cada Agente Deve Monitorar

| Agente | Monitora | Frequência | Ação |
|--------|----------|------------|------|
| **Fiscal** | GitHub Releases ERPNext + Issues + Forum NT | Diária | Detectar quebra de compatibilidade fiscal |
| **Produto** | Frappe Framework releases + Frappe Build talks | Semanal | Atualizar padrões de desenvolvimento |
| **Growth** | The Frappe Times + Forum + Marketplace | Semanal | Oportunidades de conteúdo, parcerias |
| **Suporte** | Issues + Forum + Upgrade Guide | Diária | Problemas conhecidos, workarounds |
| **Compliance** | Licenças de apps + Forum regional | Mensal | Mudanças de licenciamento, riscos legais |
