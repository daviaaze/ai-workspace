# Pi Skill Catalog — Personal Workspace

Generic skills sourced from `pi-setup/` and deployed to `~/.pi/agent/skills/`.
Work-specific skills (Jira, commit/PR, deploy, stack-ref, validate-*, review,
confluence, datadog, daily) live in the **work** scope's own `pi-setup/skills/`
and are intentionally **not** kept in this personal workspace.

## Installed
| Skill | Purpose |
|---|---|
| `deep-research` | Recursive deep research |
| `nixfiles` | Manage personal Nix configs |
